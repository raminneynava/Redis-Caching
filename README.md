# Redis Caching Project

This project demonstrates how to implement caching with Redis in a .NET 8 application. The project uses Redis to store and retrieve product data to reduce database load and improve performance.

## Features

- **Product Management**: Allows adding, updating, and deleting products.
- **Redis Caching**: Caches product data in Redis to speed up data retrieval.
- **ASP.NET Core**: Built using ASP.NET Core and Redis for caching.

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later.
- [Redis](https://redis.io/download) installed and running locally or on a server.
